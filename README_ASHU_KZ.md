# ASAR AI — 5 AI тақырыбы бірге жұмыс істейтін жоба

Бұл пакетте бастапқы **3 AI тақырыпты ASAR AI демосы** жаңартылып, Bayesian мен HMM тікелей сол қосымшаға біріктірілген.

## Дереу ашу

`ASAR_AI_Integrated_5_Topics.html` файлын екі рет басыңыз. Сайт ішінде «AI сәйкестендіру» және «AI аналитика» мәзіріне өтіңіз. Bayesian еріктіні бағалайды; HMM Forward + Viterbi ашық өтініштер жүктемесін талдайды. Бір HTML файлдан басқа ештеңе талап етілмейді.

## Мобильді React Native нұсқасы

`Mobile_App` папкасында Expo SDK 54 жобасы бар. Компьютерде `npm install`, `npx expo start` орындап, телефоннан Expo Go арқылы ашыңыз. Android APK жинақталмаған.

## Код пен тестілеу

- Дербес веб-демо: **20/20** браузерлік тест өтті (`ASAR_TESTS.run()` консольде).
- React Native есептеу ядросы: **31/31** тест өтті (`node --test tests/engine.test.mjs`).
- 1-апта: агент; 2-апта: A*; 3-апта: CSP; 6-апта: Bayesian; 7-апта: HMM.
- Bayesian CPT, HMM бастапқы/ауысу/бақылау матрицалары синтетикалық, нақты адамдар жөнінде болжам дәлдігі тексерілмеген.
- Өтініштер браузерде/телефонның жергілікті жадында сақталады, нақты адамдар арасында синхрондалмайды.
- Қалған 5 тақырып тек келешек жоспарында.
