# ASAR AI Mobile — «Бірге көмектесеміз»

**Android және iPhone үшін React Native + Expo (SDK 54) мобильді MVP.** Бұл веб-сайттың қаптамасы емес, Native React Native интерфейсі бар бастапқы телефон қолданбасы.

## Қазір қандай функциялар жұмыс істейді?

- **Басты бет:** ашық өтініштер, санаттар, қысқаша көрсеткіштер.
- **Іздеу:** атау, сипаттама, аудан бойынша іздеу және санат сүзгілері.
- **Көмек сұрау:** жаңа өтінішті толтыру, жариялау, санат ұсыну, құпия деректерді қарапайым тексеру.
- **Көмектесу:** өтінішті қабылдау, «Көмек көрсетілді» деп белгілеу.
- **Өтініш иесі ретінде растау:** өз өтінішін аяқталған деп растау.
- **AI сәйкестендіру:** жарамды еріктілерді ұсыну, A* символдық маршрут, түсіндірілген балл; Bayesian демо ықтималдығы.
- **AI аналитикасы:** HMM Forward/Viterbi арқылы сұраныс қарқынын болжау; үш синтетикалық сценарийді салыстыру.
- **Профиль:** демо рөлі, аудан, көмектесу санаттары, қолжетімділік.
- **Жергілікті сақтау:** AsyncStorage арқылы телефонда сақталады, қайта ашылғанда жоғалмайды.

**МАҢЫЗДЫ:** қолданба *демонстрациялық*. Бастапқы өтініштер мен еріктілер — ойдан шығарылған. Бекіту, хабарлама, карта және маршрут — нақты адамдарға әсер етпейді. Бір телефондағы деректер екінші телефонға синхрондалмайды.

## Телефонда ашу (компьютер + телефон қажет)

1. Компьютерге [Node.js LTS](https://nodejs.org/) орнатыңыз.
2. Телефонға [Expo Go](https://expo.dev/go) орнатыңыз. **Бұл жобаның Expo SDK нұсқасы — 54.** Егер Expo Go «incompatible» десе, SDK 54-ке сәйкес Expo Go орнатыңыз (Android-та expo.dev/go арқылы SDK 54-ті таңдаңыз). iPhone-да қолданба нұсқасы SDK 54-ті қолдауы қажет.
3. ZIP-ті компьютерде шығарып, `ASAR_AI_Mobile` бумасын ашыңыз.
4. Windows-та `start_windows.bat` файлын екі рет басыңыз. Немесе терминалда:

```bash
npm install
npx expo start
```

5. Телефон мен компьютер бір Wi-Fi желісінде болсын. Expo Go ішінен (Android) немесе телефон камерасымен (iPhone) терминалда шыққан QR-кодты сканерлеңіз. iPhone-да қажет болса компьютердегі Expo CLI мен Expo Go-ға бір Expo аккаунтымен кіріңіз.
6. ASAR AI телефондағы Expo Go арқылы ашылады.

*Интернет пакеттерді алғашқы рет орнатуға қажет. Проект Expo Go ішінде ашылғанда сервер (Metro) компьютерде іске қосылып тұруы керек.*

## APK шығару (болашақта)

Жоба ішіндегі `eas.json` файлы APK жинауға арналған preview конфигурациясымен берілген. Expo аккаунтымен және желіге қосылған компьютерден:

```bash
npm install
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

EAS Build ресми cloud build қызметі APK дайындап береді. Бұл чатта APK **жасалған жоқ** және бұл жүктелетін файл APK емес. iPhone-ға өз алдына орнатылатын production-нұсқа тарату үшін Apple Developer / TestFlight процестері керек.

## Тесттер

```bash
node --test tests/engine.test.mjs
```

31 тест: алғашқы 16 тест + Bayesian есептері (6), HMM есептері (9). Байес формуласы қолмен есеппен, HMM Forward таралуы және Viterbi күй жолы тексеріледі.

### AI сабақтарымен байланысы

**Нақты жазылған:** 1 — Rule-based agent, 2 — A* іздеу, 3 — CSP backtracking және шектеулер, **6 — Bayesian Network**, **7 — HMM Forward/Viterbi**. Қосымшада мәтін санатын ұсынатын ережелік функция бар, ол **үйретілген ML емес**. **Жоспардағы модульдер:** 4 — Minimax, 5 — Q-learning, 8 — Machine Learning, 9 — Neural Network, 10 — LLM және AI Safety. Бұл 5 модульдің толық іске асқанын мәлімдемейміз. CSP тақырыбындағы Hill Climbing әзірге жоспарланған.

### Қауіпсіздік және құпиялық

- SMS, push, тіркелу, нақты волонтерді верификациялау, модерация, сервер, нақты карта, төлем жоқ.
- `AsyncStorage` шифрланбаған; құпия деректер үшін қолданылмайды. Нақты мекенжай, ЖСН, телефон, карта нөмірі немесе пароль енгізуге болмайды.
- Бұл шұғыл медициналық немесе құтқару қызметі емес. Төтенше жағдайда 112-ге хабарласыңыз.
- Халыққа жариялау алдында backend, қауіпсіз авторизация, рұқсаттар, модерация, деректерді шифрлау, аудит, заңгерлік тексеру және еріктілерді верификациялау қажет.

## Жаңарту 1.1 — Bayesian + HMM

**Bayesian (6-апта)** `bayesianAcceptance(evidence)` функциясы P(accepted | nearby, lowLoad, today) мәнін conditional probability tables арқылы есептейді. `estimateAcceptance(request,volunteer)` бұл есепті маршрут пен ерікті дерегіне байланыстырады. Нәтижесі «AI еріктілерді ұсынсын» терезесінде көрсетіледі. `rankVolunteers()` бұрынғы эвристикалық баллды сақтайды; Байес ықтималдығы оны автоматты ауыстырмайды.

**HMM (7-апта)** `inferDemandHMM(counts)` функциясы 3 жасырын күйге (Төмен / Орташа / Жоғары) арналған forward filtering, one-step prediction және Viterbi алгоритмдерін іске асырады. «AI аналитикасы» бетінде соңғы кезеңнің ашық өтініш саны және алдыңғы 6 кезеңнің *жасанды* жүктеме тарихы қолданылады. Тарих сценарийін ауыстыруға болады.

**Біріккен веб-демо:** `ASAR_AI_Browser_Demo.html` файлын ашыңыз — онда бұрынғы Agent, A*, CSP беттері және Bayesian мен HMM бір интерфейсте жұмыс істейді. Жеке `ASAR_AI_Bayesian_HMM_Live_Demo.html` файлы қосымша факультативті зертхана ретінде қалдырылған. Негізгі мобильді React Native қолданбасы Expo Go арқылы ашылады.

Математика, CPT және тест жоспарларын `docs/BAYES_HMM_TECH_KZ.md` файлынан қараңыз.
